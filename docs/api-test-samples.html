Gvairad Game API Test Samples

Base URL: http://localhost:3000

Content-Type: application/json for all POST requests unless noted otherwise.

Important test flow: Run registration first, then login, then points APIs. Some APIs depend on an existing user and stored cookie/session.

Global password: rofuclav

1. Auth APIs

1.1 POST /auth/register

Purpose: Register a doctor.

{
  "doctorName": "Dr. Test One",
  "doctorRplId": "RPL-1001",
  "phoneNumber": "01712345678",
  "mioId": "MIO-5001",
  "password": "rofuclav"
}

Expected success keys: ok, created, message, user

1.2 POST /auth/login

Purpose: Login from a new browser or device.

{
  "phoneNumber": "01712345678",
  "password": "rofuclav"
}

Expected success keys: ok, message, user

1.3 GET /auth/me

Purpose: Get currently logged-in doctor using auth cookie.

Postman note: Use this after successful login in the same Postman session.

1.4 POST /auth/logout

Purpose: Clear login cookie.

{}

1.5 POST /auth/send-otp

Purpose: Send OTP to a mobile number.

{
  "mobile": "01712345678"
}

Expected success keys: ok, message, ttlMinutes

1.6 POST /auth/verify-otp

Purpose: Verify OTP for a mobile number.

{
  "mobile": "01712345678",
  "code": "4444"
}

Note: In development, code 4444 works only when ALLOW_TEST_OTP=true and an unconsumed OTP already exists for that number.

2. User APIs

2.1 POST /users/upsert

Purpose: Create or update user profile fields used by the older flow.

{
  "mobile": "01712345678",
  "name": "Dr. Test One",
  "territory": "12345",
  "instituteName": "Test Medical College"
}

Expected success keys: ok, created, user

2.2 GET /users/by-mobile?mobile=01712345678

Purpose: Fetch a user by mobile number.

3. Points APIs

3.1 POST /points/add

Purpose: Add score/points to a user.

{
  "mobile": "01712345678",
  "points": 25,
  "reason": "game_win",
  "sessionId": "session-001",
  "meta": {
    "level": 2,
    "source": "postman-test"
  }
}

Expected success keys: ok, user, points

3.2 GET /points/leaderboard

Simple sample: /points/leaderboard?limit=10&offset=0

With my_point by mobile: /points/leaderboard?limit=10&offset=0&mobile=01712345678

With my_point by userId: /points/leaderboard?limit=10&offset=0&userId=1

3.3 GET /points/me?mobile=01712345678

Purpose: Get one user's total points, last score, and rank.

3.4 GET /points/history

By mobile: /points/history?mobile=01712345678

By userId: /points/history?userId=1

With filter: /points/history?mobile=01712345678&start=2026-04-01&end=2026-04-12&reason=game_win

4. Negative Test Samples

4.1 Wrong global password

{
  "phoneNumber": "01712345678",
  "password": "wrongpass"
}

Expected response: { "ok": false, "message": "Invalid global password" }

4.2 Unknown doctor login

{
  "phoneNumber": "01999999999",
  "password": "rofuclav"
}

Expected response: { "ok": false, "message": "Doctor not found" }

4.3 Duplicate RPL registration

{
  "doctorName": "Dr. Another",
  "doctorRplId": "RPL-1001",
  "phoneNumber": "01811111111",
  "mioId": "MIO-7777",
  "password": "rofuclav"
}

Expected response: { "ok": false, "message": "Doctor RPL ID already registered" }
