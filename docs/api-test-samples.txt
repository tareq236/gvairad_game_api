Gvairad Game API Test Samples
=============================

Base URL: http://localhost:3000
Content-Type: application/json
Global Password: rofuclav

Important test flow:
1. Register a doctor
2. Login
3. Check auth/me
4. Add points
5. Check points APIs

1. Auth APIs
------------

1.1 POST /auth/register
Purpose: Register a doctor

Sample body:
{
  "doctorName": "Dr. Test One",
  "doctorRplId": "RPL-1001",
  "phoneNumber": "01712345678",
  "mioId": "MIO-5001",
  "password": "rofuclav"
}

Expected success keys:
- ok
- created
- message
- user

1.2 POST /auth/login
Purpose: Login from a new browser or device

Sample body:
{
  "phoneNumber": "01712345678",
  "password": "rofuclav"
}

Expected success keys:
- ok
- message
- user

1.3 GET /auth/me
Purpose: Get current logged-in doctor using auth cookie
Postman note: Use after login in the same Postman session

1.4 POST /auth/logout
Purpose: Clear login cookie

Sample body:
{}

1.5 POST /auth/send-otp
Purpose: Send OTP to mobile

Sample body:
{
  "mobile": "01712345678"
}

Expected success keys:
- ok
- message
- ttlMinutes

1.6 POST /auth/verify-otp
Purpose: Verify OTP

Sample body:
{
  "mobile": "01712345678",
  "code": "4444"
}

Note:
- In development, 4444 works only when ALLOW_TEST_OTP=true
- There must already be an unconsumed OTP for that number

2. User APIs
------------

2.1 POST /users/upsert
Purpose: Create or update old-flow user profile

Sample body:
{
  "mobile": "01712345678",
  "name": "Dr. Test One",
  "territory": "12345",
  "instituteName": "Test Medical College"
}

Expected success keys:
- ok
- created
- user

2.2 GET /users/by-mobile?mobile=01712345678
Purpose: Fetch a user by mobile number

3. Points APIs
--------------

3.1 POST /points/add
Purpose: Add score/points to user

Sample body:
{
  "mobile": "01712345678",
  "points": 25,
  "reason": "game_win",
  "sessionId": "session-001",
  "meta": {
    "level": 2,
    "source": "postman-test"
  }
}

Expected success keys:
- ok
- user
- points

3.2 GET /points/leaderboard
Simple sample:
/points/leaderboard?limit=10&offset=0

With my_point by mobile:
/points/leaderboard?limit=10&offset=0&mobile=01712345678

With my_point by userId:
/points/leaderboard?limit=10&offset=0&userId=1

3.3 GET /points/me?mobile=01712345678
Purpose: Get total points, last score, and rank

3.4 GET /points/history
By mobile:
/points/history?mobile=01712345678

By userId:
/points/history?userId=1

With filter:
/points/history?mobile=01712345678&start=2026-04-01&end=2026-04-12&reason=game_win

4. Negative Test Samples
------------------------

4.1 Wrong global password
{
  "phoneNumber": "01712345678",
  "password": "wrongpass"
}

Expected:
{ "ok": false, "message": "Invalid global password" }

4.2 Unknown doctor login
{
  "phoneNumber": "01999999999",
  "password": "rofuclav"
}

Expected:
{ "ok": false, "message": "Doctor not found" }

4.3 Duplicate RPL registration
{
  "doctorName": "Dr. Another",
  "doctorRplId": "RPL-1001",
  "phoneNumber": "01811111111",
  "mioId": "MIO-7777",
  "password": "rofuclav"
}

Expected:
{ "ok": false, "message": "Doctor RPL ID already registered" }
